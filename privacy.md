# Privacy Policy

Last updated: 4 October 2026

This policy explains how Hermes Mongo handles data.

## Who we are

Hermes Mongo is a personal automation tool. The owner is the only user. Contact: elliottsheerin@gmail.com.

## Data we access

The tool accesses Google account data only after the owner grants OAuth permission. The data can include Google Drive files, file metadata, and the owner's email address.

## How we use data

The tool uses the data to carry out tasks that the owner requests. Examples include reading files, syncing files, and organising files.

The tool does not use the data for advertising. The tool does not sell the data.

## How we store data

The tool stores OAuth tokens and credentials on the owner's own device. The tool does not send the data to third parties.

## Sharing

The tool does not share data with third parties. The tool does not transfer data to other companies.

## Google API Services User Data Policy

The tool's use of Google user data complies with the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Retention and deletion

The owner can revoke access at any time. To revoke access, visit the [Google account permissions page](https://myaccount.google.com/permissions). Revocation removes the stored tokens.

To request deletion of stored data, send an email to elliottsheerin@gmail.com.

## Changes to this policy

We may update this policy. We will publish the new version on this page.
